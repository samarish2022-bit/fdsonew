Добавленные новости

Новости сохраняются в data/news.json. Откройте админку и сайт по адресу сервера (например http://localhost:3000) — тогда добавленные новости будут отображаться на сайте для всех устройств. Без сервера: «Экспорт JSON» → в data/news.json; при открытии по file:// — «Экспорт JS» → data/news-data.js.

      Редактировать соревнование

      Изображение сохраняется на сайте и отображается в карточках соревнований.

      Редактировать новость
      Редактировать документ

      Оставьте URL пустым и не загружайте файл — сохранится текущий документ.

      Редактировать ссылку
      Добавить фотографию

      Укажите путь (напр. images/uploads/img-1.jpg) или выберите файлы. Для всех выбранных — одно соревнование и подпись.

      Фото будут сгруппированы по названию соревнования на сайте.

      Добавленные фотографии

      Фотографии сохраняются на сервере: файлы — в images/uploads/photos/<соревнование>/, список — в data/photos.json. Откройте админку по адресу сервера (npm start) — тогда загрузка и галерея будут работать для всех.

      Пока нет добавленных фотографий.

      Добавить документ

      Укажите ссылку или выберите файл (PDF, DOC, DOCX). Размер хранилища ограничен (~5 МБ).

      Добавленные документы

      Файлы сохраняются в images/uploads/documents/, список — в data/documents.json (без base64). Откройте админку через сервер (npm start), чтобы загрузка работала.
